# Las diez reglas fundamentales de la sintaxis de java script

1. las instrucciones terminan en punto y coma (;)
2. los numeros decimales utilizan el punto
3. los literales de texto van entre comillas dobles ("...") o simples ('...')
4. se usa let, const o var para declarar variables
5. el operador de asignacion es el signo igual (=)
6. operadores aritmeticos: +,-,*,/,%
7. las expresiones pueden combinar variables y expresiones
8. comentarios de una linea  (//) y multilinea (/*...*/)
9. los identificadores empiezan por letras, guion bajo (_) o dolar ($)
10. case-sensitive:java sccript distingue entre mayusculas y minusculas (entonces nombre y Nombre son diferentes)
